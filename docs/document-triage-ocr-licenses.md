# Document triage OCR notices

The OCR components used by SOCLE are part of the full third-party component inventory in [COMPOSANTS-TIERS.md](COMPOSANTS-TIERS.md). That notice records the delivered files, package versions, license references, and build provenance.

The OCR worker, WebAssembly core, and French model are served by SOCLE itself. The browser does not send document contents to an OCR provider.
